What works: The game initializes the loader window and logs kernel trace calls.

What breaks: The game fails to boot into intro videos or the main menu. It gets stuck in a black window and an infinite ORBIS_GEN2_ERROR_TIMED_OUT loop while attempting libKernel:scePthreadMutexLock and scePthreadMutexUnlock operations.
