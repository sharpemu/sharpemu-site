The game boots and immediately loads into the main menu's animated space background. The moving starfield animation successfully renders at around 1.9 to 2.9 FPS with active 5/5 draws.

![Image](https://github.com/user-attachments/assets/18ef5d60-3d92-44ba-b8e1-a57d73623554)

The main menu buttons and UI text elements are completely invisible over the animated background. The game is stuck in an input deadlock where no keyboard or controller inputs register. Testing with debug flags like WRITABLE_APP0 and GUEST_IMAGE_CPU_SYNC did not resolve the issue.
